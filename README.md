# WebRSS

一个无需构建工具、无需后端服务的静态 RSS 阅读器。用浏览器打开 `index.html` 即可使用；也可以将文件发布到任意静态网站托管服务。

## 配置订阅源

部署者在 [app.js](./app.js) 顶部的 `FEEDS` 数组中维护订阅源：

```js
const FEEDS = [
  { title: "示例站点", url: "https://example.com/feed.xml" },
];
```

读者不能增删订阅源。页面读取 RSS 2.0、RSS 1.0 和 Atom；点击文章标题可在站内查看订阅源提供的正文，若订阅源只提供摘要，可通过“查看原文”前往文章页面。已读状态保存在当前浏览器中。

页面适配手机屏幕，无需构建工具、后端服务或运行时依赖。

## 跨域说明

浏览器的同源策略会阻止网页直接读取许多 RSS 服务。阅读器先尝试直接请求订阅源；如果源站不允许跨域读取，则通过公开的 AllOrigins 代理再次尝试。该代理是第三方服务，可能暂时不可用；出现失败时可稍后重试，或在支持跨域访问的 RSS 服务上使用此阅读器。订阅地址由浏览器直接请求，不会经过本项目的服务器。

文章正文会移除脚本和不支持的标签后再显示。
